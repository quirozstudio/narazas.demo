# NARAZAS — reglas del proyecto

- Mantener una dirección visual editorial, cálida y personal; no convertir la demo en un ecommerce genérico.
- Diseñar mobile-first para 360–430 px y adaptar después a tablet y escritorio.
- Reutilizar componentes y centralizar contenidos editables.
- Mantener HTML, CSS y JavaScript limpios, semánticos y fáciles de mantener.
- Priorizar rendimiento, accesibilidad, navegación por teclado y estados de foco visibles.
- Evitar dependencias innecesarias y no añadir funcionalidades no solicitadas.
- No cambiar la dirección artística sin una razón clara y documentada en `SPEC.md`.
- Mantener nombres de productos, precios, imágenes y textos fáciles de localizar y sustituir.
- Usar animaciones sutiles y respetar `prefers-reduced-motion`.
- Esta fase es una demo comercial: no añadir pagos, backend, autenticación, base de datos o entregas reales sin petición explícita.
